# MUTAGENÊSES

Sistema e plataforma online de RPG pós-apocalíptico.

## Arquitetura
- GitHub Pages: publicação do frontend.
- Supabase: autenticação, banco de dados, armazenamento de imagens e sincronização.
- Cada usuário terá seus próprios personagens, itens, capacidades e ameaças.
- Comunidades e campanhas poderão conectar jogadores mediante permissões.
